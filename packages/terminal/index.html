    Prepaid credits, precise privacy.

    Test stablecoins are held in an EVM treasury. Its payments, amounts and refunds are public. An operator relay verifies finalized source payments and authorizes credits on Midnight; that relay is trusted.

    Credit balances are represented by private notes. Your encrypted payment backup can recover later unspent balances. The trusted local app and proof server process note openings. Wallet keys remain in their wallet extensions.

    One credit authorizes one request in this demo. Choose a configured model before spending. Paid retries keep the original model and prompt. Gateway and model see request content. Unspent credits can be burned for a matching treasury refund; consumed credits are no longer refundable.

    This deployment uses valueless local test tokens and has no yield or investment return. Public Sepolia/Preview bridge deployment and production security review remain separate steps.
